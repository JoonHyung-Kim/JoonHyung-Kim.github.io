AI를 활용한 포트폴리오 웹사이트 개발

개인 프로젝트 · 2026.09 ~ 진행 중

웹 개발 전공자는 아니지만, 취업 준비 기간 동안 이 포트폴리오 웹사이트를 기획부터 배포까지 직접 만들었습니다. AI(Claude)의 도움을 받아 HTML/CSS와 Git을 하나씩 익히며 실제 서비스를 완성해봤습니다.

과정
HTML/CSS 문법을 하나씩 물어보고 직접 적용해가며 페이지를 만들었습니다. GitHub에 올리는 과정에서 push가 거절되는 상황을 실제로 겪었는데, 원인이 원격 저장소와 로컬 사이의 충돌이라는 것을 파악하고 병합 과정을 직접 진행하며 문제를 해결했습니다.
배운 점
AI가 제안한 코드를 그대로 쓰기보다, 왜 이렇게 동작하는지 먼저 물어보고 실제 화면에서 확인한 뒤 다음 단계로 넘어갔습니다. 오류가 생겼을 때도 원인을 직접 찾아 해결하면서, AI는 방법을 빠르게 알려주는 도구일 뿐 최종 판단과 확인은 결국 사람의 몫이라는 것을 체감했습니다.

담당 역할: 기획, HTML/CSS 개발, Git/GitHub 배포
